Developer notes

Use data attributes when templates or CMS fields need to declare rules without custom JavaScript per field.

Data rules

<input
  name="email"
  type="email"
  data-validate="required email"
  data-message-required="Email is required."
  data-message-email="Use a valid email address."
/>

Minimal setup

new A11yFormValidator(
  document.getElementById("cms-form"),
  createMinimalPreset()
);
