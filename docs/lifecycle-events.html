    Developer notes

    The parent section subscribes before initialization, so it observes init and every later bubbling event. Event handlers are observations; commands still use validator methods.

    Typed subscription

    validator.events.on(EVENTS.errorsChanged, (event) => {
  console.log(event.detail.source, event.detail.errors);
});

    Delegated DOM listener

    root.addEventListener(EVENTS.fieldPending, (event) => {
  console.log(event.target, event.currentTarget);
});
