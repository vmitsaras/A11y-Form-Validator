Import notes

The minified file is a direct-browser convenience entry. It is not the default package export, and it keeps the same public runtime API as dist/index.js.

Direct browser import

<script type="module">
  import {
    createDefaultPreset,
    createFormValidator
  } from "../dist/index.min.js";

  const form = document.querySelector(
    "[data-a11y-form-validator]"
  );

  if (form instanceof HTMLFormElement) {
    createFormValidator(form, createDefaultPreset());
  }
</script>

Bundler import stays normal

import {
  createDefaultPreset,
  createFormValidator
} from "a11y-form-validator";

import "a11y-form-validator/styles.css";
