Developer notes

Server responses can add field-level and form-level errors after client-side validation has already run.

Server response shape

validator.setErrors({
  email: "This email is already registered.",
  form: "Your session expired. Reload the page."
});

Announce errors

document.getElementById("mock-server").addEventListener("click", () => {
  validator.setErrors({
    email: "This email is already registered.",
    form: "Your session expired. Reload the page."
  });
  validator.focusOnError();
});
